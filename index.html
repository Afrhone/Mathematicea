Hosting options

This interface is pure HTML, CSS, and JavaScript. Enable GitHub Pages for the repository root or serve the same files from any static hosting provider.

  1. Commit the root index.html and src/web-*.css/js files.
  2. In GitHub, open Settings → Pages.
  3. Select Deploy from a branch, choose this branch, and set the folder to /root.
