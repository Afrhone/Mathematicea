# Stack

## Frontend

- Next.js or Vite React
- Tailwind
- Recharts
- React Flow
- Three.js optional

## Backend

- FastAPI or Node/NestJS
- PostgreSQL
- Redis
- Docker SDK / shell adapter
- SSH adapter with strict allowlist
- OpenAI-compatible local model endpoint
- Qdrant or Chroma for RAG

## Infrastructure

- Docker Compose for MVP
- Swarm only after MVP is stable
- Caddy or Nginx
- GitLab CI
- LXD integration later

## Payment

- Stripe for subscriptions
- Gumroad/Ko-fi/LemonSqueezy for digital bundles
- Invoice-first for Swiss B2B consulting
