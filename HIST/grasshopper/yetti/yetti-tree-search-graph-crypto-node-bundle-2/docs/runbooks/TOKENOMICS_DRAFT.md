# YETTI Tokenomics Draft

## Name

```text
YETTI Snow Credits
```

## Symbol

```text
YETTI
```

## Initial dev supply

```text
715,000,000 YETTI
```

## Intended private-dev use

- contribution accounting
- gate approvals
- automation-world credits
- test DAO proposals
- dashboard badges
- local tribe simulations

## Conservative public design option

For the first public documentation release, keep YETTI as:

```text
non-sale
non-investment
dev/testnet
no liquidity
no redemption
no profit claims
```

## Safer distribution options

1. **Soulbound / non-transferable test credit**
2. **Private testnet ERC-20**
3. **Capped closed-beta utility token**
4. **Public transferable token only after full review**

## Mint controls

Current contract supports minters and mint lock. Before public release add:

- capped supply hard limit
- timelock for admin actions
- multisig ownership
- pausable emergency mode
- role revocation
- event-based disclosure
- migration policy

## Prohibited tokenomics language

Do not write:

```text
number go up
investment
yield
free money
guaranteed return
revenue share
dividend
profit
```
