# Uniphi-Alchemy Map — Bundle

A lightweight, offline-first framework to map a creative/technical project as an alchemical process:
vision, structure, security, play, noise, and witness — all in one living document.

## What’s inside

- `axioms/axioms_en_fr_la.md` — Motto-style axioms (Latin + French + English). Some are neo-Latin inventions for clarity and vibe.
- `templates/uniphi-alchemy-map-template.md` — Fillable template (Markdown).
- `templates/uniphi-alchemy-map-schema.json` — JSON schema you can use for validation / tooling.
- `web/uniphi-alchemy-map.html` — Single-file web app (no build tools, no dependencies).
- `examples/` — Example map in Markdown + JSON.
- `tools/` — Tiny helper scripts (optional).

## Quick start (web app)

1. Open `web/uniphi-alchemy-map.html` in your browser.
2. Fill the map.
3. Export Markdown or download JSON.
4. Re-import JSON anytime.

Tip: the app stores your current draft in `localStorage` automatically.

## Quick start (Markdown)

Copy `templates/uniphi-alchemy-map-template.md` to a project folder and fill it like a lab notebook.
