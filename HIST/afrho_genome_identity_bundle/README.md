# AFRHO Genome Identity Bundle

This bundle contains:
- `afrho_genome_identity.json` — safe JSON model built from the visible ancestry screenshots plus a synthetic DNA demo.
- `genotype_to_phenotype_infographic.svg` — conceptual infographic showing chromosome → gene → codon → protein → phenotype.
- `dna_json_atlas.svg` — minimal kinetic/Tinguely-inspired ancestry + JSON atlas.

Important:
These files do **not** contain your full genome. A screenshot of ancestry percentages cannot reveal full DNA, codons, proteins, chromosomes, or medically valid phenotype predictions.

To generate a real genomic JSON, provide a raw DNA export such as:
- VCF
- FASTA/FASTQ
- 23andMe/Ancestry/MyHeritage raw SNP TXT/CSV

Privacy:
Do not publish raw DNA files. They are uniquely identifying and can reveal information about relatives too.
