# Safety Boundary

This bundle implements:

- educational physics/chemistry visualizations
- SDR spectrogram observation
- VR/AR UI experiments
- graph and GNN scaffolds
- agent-assisted analysis

It does not implement:

- real force fields
- zero-point energy extraction
- time freezing
- medical diagnosis from EEG
- coercive psychometric profiling
- RF transmission automation
- exploit or stealth tooling

All claims emitted by the agent gateway should be treated as commentary until verified by measurable instrumentation.
