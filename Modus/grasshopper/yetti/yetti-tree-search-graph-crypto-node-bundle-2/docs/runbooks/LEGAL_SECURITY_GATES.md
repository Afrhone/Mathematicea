# Legal and Security Gates

## Legal classification gate

Before any public token action, answer:

```text
1. Is YETTI transferable?
2. Is there a sale?
3. Is there fundraising?
4. Is there any expectation of profit?
5. Do holders rely on a core team for value?
6. Does YETTI provide only access/utility?
7. Is it usable at issuance?
8. Are there asset, revenue, dividend, or interest rights?
9. Are there AML/KYC obligations?
10. Which jurisdictions can access it?
```

## Switzerland gate

Classify against:

```text
payment token
utility token
asset token
hybrid token
```

## EU gate

Check whether a crypto-asset white paper and MiCA/MiCAR obligations apply, especially if offered to the public or admitted to trading in the EU.

## US gate

Avoid public US distribution until counsel reviews whether facts could create an investment-contract/security issue.

## Security gate

Before public release:

```text
static analysis
unit tests
fuzz tests
admin role review
mint cap review
multisig ownership
timelock
emergency pause
upgrade/migration policy
independent audit
bug bounty / responsible disclosure
```

## Infrastructure gate

```text
private keys isolated
RPC rate limits
monitoring
incident response
backups
logs
chain indexer
public status page
```
