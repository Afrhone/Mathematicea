Integrated as an operational metaphor:

```text
moving fixed point      → target invariant under changing cluster conditions
coordinate change       → namespace, storage, route, runtime, role changes
shared manifold         → common cluster substrate
catastrophic forgetting → a fix that breaks an older invariant
```

## Curvature budget

A repair perturbs the manifold. The gate asks:

```text
Will this repair preserve more invariant structure than it destroys?
```

## Learning loop

```text
state epoch
→ graph embedding
→ drift score
→ entropy score
→ gate candidate
→ human/APPLY flag
→ mutation
→ post-state sink
```
