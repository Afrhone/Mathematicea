Octopuce Brainfield System — High-Fidelity Model
=================================================

This is an upsampled / higher-resolution version of the organic
brainfield system, with denser cortex folds, smoother tubes,
more neuron nodes, and higher-resolution shells and fields.

Files
-----
- octopuce_brainfield_system_hires.obj   : Hi-res layered brain model with named groups.
- octopuce_brainfield_system_hires.mtl   : Materials with colors + alpha hints.

Groups / Zones (same semantics as base model)
--------------------------------------------
- cortex_left, cortex_right
- limbic_core
- cerebellum
- brainstem
- neural_tree
- neuron_nodes
- brainwave_shell_outer / mid / inner
- energy_field

Use this variant when you need closer shots, smoother silhouettes,
or more detailed displacement / morphing in your shaders.
