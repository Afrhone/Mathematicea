# Mendeleev Quantum-Matter Lab

This module transforms the screenshots' idea into a **reviewable simulation interface**, not an asserted law of matter.

## Period formula playground

```text
c(p) = 2 · [Int((p + 2) / 2)]²
```

Use as an exploratory visualization for periodic-table layer counts and symmetry/asymmetry patterns.

## Matter concept graph

```text
element → quantum numbers → orbital heuristic → geometry tile → hypergraph node → generative token metadata
```

## Three.js periodic table

The UI overlay includes a CSS3D periodic table widget inspired by the official Three.js CSS3D periodic table example.

## Safety

The app labels the Perez/Mendeleev arithmetic as a conceptual model and visual hypothesis, not validated chemistry.
