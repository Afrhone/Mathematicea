# Metabolic Engine: Compost, Ferment, Distill, Canonize

The engine processes data like an ecosystem.

```text
raw lake -> compost chunks -> ferment summaries -> wiki pages -> canon promotion
```

## Trash engine

Trash does not mean worthless. It means unstructured:

- logs;
- notes;
- bookmarks;
- screenshots described in text;
- repository summaries;
- agent outputs;
- camera annotations;
- failed attempts;
- contradictions.

## Sustainable transmutation beautifier

The beautifier makes raw material readable without hiding provenance. Every promoted page keeps source hashes and links to chunk files.

## Neurodivergence pattern extractor

This module extracts patterns of cognition and interface need without diagnosing people:

- nonlinear association;
- high context switching;
- sensory load;
- urgency spikes;
- forgotten bookmarks;
- divergent naming;
- repeated panic loops;
- useful obsessive detail.

The output is used to improve UI affordances and agent prompts, not to label humans.
