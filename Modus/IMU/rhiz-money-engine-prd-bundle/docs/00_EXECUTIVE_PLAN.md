# Executive Plan

## Money thesis

The project should not start as a giant everything-machine. It should start as paid surfaces extracted from the existing universe:

1. Cash now — paid dev/ops recovery sessions.
2. Slow income — monthly maintenance subscriptions.
3. Passive-ish income — templates, bundles, courses, paid knowledge base.
4. Speculative upside — art drops, tokenized membership, crypto treasury.
5. Aggressive trading — sandboxed research branch with hard risk limits.
