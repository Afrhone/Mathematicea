# References

## Differential geometry grounding

Primary note used as conceptual grounding:

- Joel W. Robbin and Dietmar A. Salamon,
  *Introduction to Differential Geometry*,
  ETH Zürich / UW Madison notes,
  version dated 27 October 2024.
  URL:
  https://people.math.ethz.ch/~salamon/PREPRINTS/diffgeo.pdf

Core themes borrowed at a conceptual level:
- vector fields and flows,
- Levi-Civita connection,
- geodesics as critical points of the energy functional,
- exponential map and injectivity radius,
- curvature and isometries.

## Scope reminder

The implementation in this bundle is not a direct transcription of the source notes.
It is a visualization architecture inspired by that formal language.
