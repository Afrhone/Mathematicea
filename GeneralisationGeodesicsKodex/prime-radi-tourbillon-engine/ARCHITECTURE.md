# Architecture

## 1. Prime Radi Clock

`src/engine/primeClock.js` creates a clock in which every blade is indexed by a prime number.

```text
blade_i = { prime, angle, radius, torsion, angularVelocity, gate }
angle_i(t) = t / (prime_i + phi) + i * golden_angle
```

The prime index makes the clock quasi-periodic. It resists simple repetition and produces a dense phase braid.

## 2. Tourbillon Propeller Mechanics

`src/engine/mechanicsGenerator.js` transforms clock blades into a mechanics frame.

```text
dθ/dt = ω
dω/dt = drive * sin(3θ) - damping * ω - stiffness * sin(θ)
```

The ODE is integrated with RK4. It is a stable toy oscillator, not a real propeller design. The frame emits:

- angular momentum proxy
- lift proxy
- torsion proxy
- tourbillon coil vertices

## 3. UV Grid Blueprint

`src/engine/uvGrid.js` maps a rectangular UV grid to a Möbius-like manifold.

```text
u ∈ [0,1]
v ∈ [0,1]
θ = 2πu
strip = 2(v - 1/2)
twist = θ/2
r = 1 + strip * cos(twist)
```

The scalar field is generated by prime harmonics, curvature modulation, thermal perturbation, and a Higgs-like sigmoid visual channel.

## 4. Calculus Lexical Functor

`src/engine/calculusFunctor.js` makes calculus terms executable:

- `derivative1D(samples, dx)`
- `gradient2D(field, width, height)`
- `divergence2D(vx, vy, width, height)`
- `curl2D(vx, vy, width, height)`

This creates a bridge between vocabulary, code, and visualization.

## 5. Compute Engine Array

`src/engine/computeArray.js` computes the field and derived calculus arrays each tick.

```text
step(t):
  field, vx, vy = samplePrimeRadiField(t)
  gradient = ∇field
  divergence = ∇·v
  curl = ∇×v
  validation = thermodynamicGuard(field, v)
```

## 6. Compute Turn Engine

`src/engine/turnEngine.js` unifies compute and mechanics.

```text
turn():
  field = compute.step()
  mechanics = generateMechanicsFrame(field.tick)
  tourbillon = makeTourbillonVertices(mechanics)
```

This is the orchestration seam for agents, UI, tests, and future WebGPU kernels.

## 7. Rendering

`src/render/threeScene.js` renders:

- colored point-cloud Möbius field
- prime tourbillon line coil
- background particle shell

The visual channels use `standardModelToy.js` only as a symbolic color vocabulary.

## 8. WebGPU Hook

`src/shaders/primeRadi.compute.wgsl` mirrors the CPU field kernel. The default app uses CPU + Three.js for compatibility. The shader is ready for future explicit WebGPU buffer orchestration.
